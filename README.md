# DirectShare v4 — Global Anonymous File Sharing

**DirectShare v4** is a native Android application built with **Kotlin** and **Jetpack Compose (Material 3 Crimson & Deep Black Obsidian Glass design)** featuring a **Startup Loading & 3-Language File Sharing Guide (English, हिंदी, বাংলা)** and a completely consumer-friendly UI that hides all underlying technical and backend implementation details from end users.

## What's New in DirectShare v4 (`v4.0.0`)

1. **Zero Technical / Backend Terminology in UI**:
   - All user-visible text across every screen, dialog, status pill, notification, and error banner has been scrubbed of technical jargon (`P2P`, `WebRTC`, `Firebase`, `DataChannel`, `Signaling`, `SDP`, `ICE`, `DTLS`, `STUN`, `TURN`, `Room`, `SAF`, `SHA-256`, `MediaStore`, `ContentResolver`).
   - Users see clean, intuitive language ("Direct Link", "Anonymous Global File Transfer", "Active Online Devices", "100% Verified & Complete", "Transfer Speed Packet Size", "Connection Boost").
2. **Startup Loading Screen + 3-Language File Sharing Guide (English, हिंदी, বাংলা)**:
   - Launches with an animated Crimson & Deep Black loading indicator and progress bar alongside a 3-language guide (**English**, **हिंदी**, **বাংলা**) with a filter selector (`All 3`, `English`, `हिंदी`, `বাংলা`).
   - Clearly explains in all 3 languages that:
     - Users can share files **anywhere in the world anonymously** with 100% privacy.
     - **2 users must keep the application open at the same time** on their phones to connect and transfer files.
   - Includes a prominent **"Next to Home"** button that navigates directly to the Home dashboard.
3. **Red & Deep Black ("Obsidian Carbon & Crimson Pulse") Flagship Layout**:
   - AMOLED Deep Black (`#050507`), Obsidian Surface (`#0B0B0F`), Vibrant Crimson Red (`#FF1744`), Scarlet Red (`#E50914`), and Deep Ruby (`#B71C1C`) across all screens and assets.
   - Synchronized `IntrinsicSize.Min` Bento cards, bounded radar nodes, equal-width 3-column live telemetry bar, and non-truncating buttons.
